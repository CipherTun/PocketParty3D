# Pocket Party 3D

A lightweight, offline-first collection of original 3D mini-games for Android.

## Planned features

- Solo play against bots
- Two to four local players on one device
- Micro Racers, Knockout Arena, and Tank Clash
- Physics-driven gameplay and responsive controls
- Cup mode, scores, rematches, and persistent settings
- Online multiplayer considered for a later stage

## Technology

- Godot Engine 4.7.2 stable
- GDScript
- Compatibility renderer
- GitHub Actions for automated validation and Android builds

## Development status

The initial repository contains the project configuration, a starter menu,
and automated project validation. The mini-games and Android APK export
are implemented in later stages.

## Build

Open `project.godot` using Godot 4.7.2 stable or a compatible newer
stable release. Install matching export templates when exporting Android.

No release signing credentials are included in this repository.
